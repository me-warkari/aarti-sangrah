← भूपाळी — घनश्याम सुंदरा श्रीधरा वाचा

  • Title: घनश्याम सुंदरा श्रीधरा (भूपाळी)
  • Deity: Krishna (Shridhara / Ghanaएका स्रोतात)
  • Language: Marathi
  • Author: Shahir Honaji Bala (Honaji Sayaji Shilarkhane, 1754–1844). PD (d. 1844). The Wएका स्रोतात page itself names him: “शाहीर होनाजी बाळा यांनी श्रीकृष्णाला उठविण्यासाठी ही भूपाळी रचलेली आहे.”
  • Size: refrain + 4 long stanzas. “Bhupali” here is the morning wake-up song form (sung at dawn, in raga Bhupali); this file gives the single best-known bhupali, Honaji Bala's, not the whole Kakad Aarti set of bhupalis (those are in kakad-aarti).

Variant readings found and decision taken

  • Refrain / opening: Wएका स्रोतात “उठीं लवकरि वनमाळी” vs sung “उठी लवकरी वनमाळी”. Decision: keep Wएका स्रोतात's old spelling in the text; the sung form is the same word.
  • Stanza 1: Wएका स्रोतात “प्रभातकाळीं उठुनि कापडी तीर्थपंथ लक्षी” vs sung “प्रभातकाळी उठुनि कावडी तीर्थ पथ लक्षी”. Decision: keep Wएका स्रोतात (“कापडी”); record the sung “कावडी” here.
  • Stanza 2, last line: Wएका स्रोतात “हंबरताति वांसरे हरि धेनुस्तन-पानाला” vs sung “लक्षिताती वासुरें हरी धेनु स्तनपानाला”. Decision: keep Wएका स्रोतात; the sung line is a different wording of the same image.
  • Stanza 4, last line: Wएका स्रोतात “होनाजी बाळा नित्य ध्यातसे ह्रुदयि नाममाळा” vs sung “होनाजी हा नित्य ध्यातसे हृदयी नाममाला”. Decision: keep Wएका स्रोतात.
  • Stanza 1, “सायंकाळी एके मेळीं” (Wएका स्रोतात) vs “सायंकाळीं एके वेळीं” (sung): kept Wएका स्रोतात.
  • The sung/recorded versions repeat the refrain and several lines for music and shorten some stanzas; those repetitions are performance practice, not text, and are not reproduced here.
