स्रोत — सत्राणे उड्डाणे

हनुमान · समर्थ रामदास · मराठी · परवाना: सार्वजनिक क्षेत्र (Public Domain) · तपासणी बाकी

← सत्राणे उड्डाणे वाचा

  • Title (Marathi): सत्राणे उड्डाणे
  • Deity: Hanuman / Maruti (श्री हनुमान)
  • Author: Samarth Ramdas (1608–1681/82). Signature "रामी रामदासा शक्तीचा शोध" in the last stanza.
  • Language: Marathi
  • Stanzas: 2 numbered stanzas + 1 refrain (ध्रुवपद, "जय देव जय देव जय श्रीहनुमंता")

Variant readings found and decision

  • A different Maruti aarti sharing only the first line circulates in some collections: its stanzas run "करि वज्रपुच्छ लंगूर परळी भजनी … / अंजनीसुता कपिकुळटिळका विशाळा … / रामदास विनवी जोडूनिया हात" with refrain "तुमचे चरणी ठेविले मस्तक अनंता". The 2-stanza Ramdas text in our file is attested by एका स्रोतात, एका स्रोतात, Milind Pandit, and एका स्रोतात; that version was NOT followed and is recorded here.
  • Stanza 1, line 3: "कडाडिले ब्रह्मांड धाके त्रिभुवनी" (एका स्रोतात, एका स्रोतात) vs "गडबडिलें ब्रह्मांड धाके त्रिभुवनी" (एका स्रोतात) — kept "कडाडिले".
  • Refrain, line 2: "तुमचेनि प्रतापे न भिये कृतांता" (एका स्रोतात, Milind Pandit) vs "तुमचेनी प्रसादें न भी कृतांता" (एका स्रोतात, एका स्रोतात) — kept "प्रतापे"; "प्रसादें" recorded as the variant.
  • Stanza 2, line 1: "दुमदुमिले पाताळ उठला पडशब्द" (एका स्रोतात) vs "दुमदुमिली पाताळें उठिली प्रतिशब्द" (एका स्रोतात) — kept "पडशब्द".
  • Stanza 2, line 2: "धगधगिला धरणीधर मानीला खेद" (एका स्रोतात) vs "थरथरला धरणीधर मानीला खेद" (एका स्रोतात) — kept "धगधगिला".
  • Last line: "शक्तीचा शोध" (एका स्रोतात, एका स्रोतात) vs "शक्तीचा बोध" (एका स्रोतात) — kept "शोध".
  • Stanza 1, line 4: "सुरवर नर निशाचर" — एका स्रोतात notes the variant reading "सुरवर, निशाचर" (without "नर"); kept "सुरवर नर निशाचर".
