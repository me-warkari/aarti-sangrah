# आरती संग्रह — Aarti Sangrah

मराठी व हिंदी आरत्यांची मुक्त वाचनालय — मूळ मजकूर, स्रोतासह, मोफत.
संतकृपा (santkrupa) या भगिनी संकेतस्थळाप्रमाणेच बांधलेली, पण आरत्यांसाठी
वेगळी रचना: एक आरती = एक पान, देवता / प्रसंग / संत यांनुसार शोध.

Site (GitHub Pages, repo तयार झाल्यावर): https://me-warkari.github.io/aarti-sangrah/

- **फक्त सार्वजनिक क्षेत्र (Public Domain).** भारत: लेखकाचे निधन ≤१९६५;
  अमेरिका: १९३० पूर्वीचे प्रकाशन किंवा मध्ययुगीन मूळ कृती.
- **दोन स्वतंत्र स्रोतांची तुलना** प्रत्येक आरतीसाठी; पाठभेद व वादग्रस्त
  कर्तृत्व `SOURCE.md` मध्ये नोंदवलेले आहे, एका अधिकाराचा दावा नाही.
- **परवानगी नसलेल्या स्रोतांतील मजकूर येथे घेतलेला नाही.** ज्या स्रोतांकडून
  पुनर्प्रकाशनाची परवानगी नाही, त्यांचे नावही सार्वजनिक पानांवर येत नाही —
  स्रोतांची नावे फक्त repository मधील `SOURCE.md` फाइल्समध्ये आहेत.
- **वगळलेले:** तुकडोजी महाराज (१ जानेवारी २०२९ पर्यंत सार्वजनिक क्षेत्रात
  नाहीत), आधुनिक / चित्रपट आवृत्त्या, अर्थ-भाष्य-भाषांतरे. साईबाबांच्या
  आरत्यांतील नमस्काराष्टक व काकड आरतीतील दोन भाग लेखक पडताळता आले नाहीत
  म्हणून वगळले आहेत — त्यांची नोंद प्रत्येक स्रोत पानावर आहे.

## रचना

```
content/<slug>/<slug>.md    मजकूर (युनिकोड देवनागरी) — source of truth
content/<slug>/SOURCE.md    लेखक, स्रोत, पाठभेद, परवाना, तपासणी
tools/build.py              जनरेटर (Python, stdlib only)
tools/assets/               style.css, reader.js, search.js
tools/fonts/                Tiro Devanagari Marathi + Mukta (SIL OFL)
site/                       तयार झालेली स्थिर पाने (GitHub Pages)
```

पाने: `/` मुख्य (आजची आरती + सर्व आरत्या), `/aarti/<slug>/` वाचन पान,
`/devata/`, `/prasang/`, `/sant/`, `/hindi/`, `/srot/<slug>/` स्रोत पान,
`/shodh/` शोध (client-side `search-index.json`), `/vishayi/` विषयी.

## बांधणी

```sh
python3 tools/build.py
```

`site/` पुन्हा तयार होते. वाचनासाठी JavaScript लागत नाही; जाहिराती,
मागोवा किंवा खाते नाही.
