# SOURCE — भूपाळी: घनश्याम सुंदरा श्रीधरा (Bhupali)

- Title: घनश्याम सुंदरा श्रीधरा (भूपाळी)
- Deity: Krishna (Shridhara / Ghanashyam)
- Language: Marathi
- Author: Shahir Honaji Bala (Honaji Sayaji Shilarkhane, 1754–1844). PD (d. 1844). The Wikisource page itself names him: “शाहीर होनाजी बाळा यांनी श्रीकृष्णाला उठविण्यासाठी ही भूपाळी रचलेली आहे.”
- Size: refrain + 4 long stanzas. “Bhupali” here is the morning wake-up song form (sung at dawn, in raga Bhupali); this file gives the single best-known bhupali, Honaji Bala's, not the whole Kakad Aarti set of bhupalis (those are in kakad-aarti).

## Sources compared

1. mr.wikisource.org, “घनश्याम श्रीधराची भूपाळी” — https://mr.wikisource.org/wiki/घनश्याम_श्रीधराची_भूपाळी — typed Devanagari text, full (refrain + 4 stanzas), tagged as public-domain literature (प्रताधिकार मुक्त साहित्य) but also “स्त्रोत नसलेली पाने” (unsourced page). Used as the base wording, old spelling retained (उठीं, लवकरि, कापडी, ह्रुदयि).
2. Saregama lyric page, “Ghanshyam Sundara Shridhara” (Amar Bhoopali) — https://www.saregama.com/song-lyrics/ghanshyam-sundara-shridhara_48163 — the sung wording as recorded; cross-checked against Pujasthan's Sai Baba Bhupali page (https://www.pujasthan.com/sai-baba-bhupali-aarti/), which prints the same bhupali in Devanagari as part of the Sai morning service.

No text, meaning, or presentation was copied from any lyric site; the text above was written from the compared wordings. The film Amar Bhoopali (V. Shantaram, 1951/52) and its recordings were NOT used as sources — only the underlying Honaji Bala text.

## Variant readings found and decision taken

- Refrain / opening: Wikisource “उठीं लवकरि वनमाळी” vs sung “उठी लवकरी वनमाळी”. Decision: keep Wikisource's old spelling in the text; the sung form is the same word.
- Stanza 1: Wikisource “प्रभातकाळीं उठुनि कापडी तीर्थपंथ लक्षी” vs sung “प्रभातकाळी उठुनि कावडी तीर्थ पथ लक्षी”. Decision: keep Wikisource (“कापडी”); record the sung “कावडी” here.
- Stanza 2, last line: Wikisource “हंबरताति वांसरे हरि धेनुस्तन-पानाला” vs sung “लक्षिताती वासुरें हरी धेनु स्तनपानाला”. Decision: keep Wikisource; the sung line is a different wording of the same image.
- Stanza 4, last line: Wikisource “होनाजी बाळा नित्य ध्यातसे ह्रुदयि नाममाळा” vs sung “होनाजी हा नित्य ध्यातसे हृदयी नाममाला”. Decision: keep Wikisource.
- Stanza 1, “सायंकाळी एके मेळीं” (Wikisource) vs “सायंकाळीं एके वेळीं” (sung): kept Wikisource.
- The sung/recorded versions repeat the refrain and several lines for music and shorten some stanzas; those repetitions are performance practice, not text, and are not reproduced here.
