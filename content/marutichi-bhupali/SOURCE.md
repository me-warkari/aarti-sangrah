# SOURCE — मारुतीची भूपाळी (Maruti Bhupali)

- Title: मारुतीची भूपाळी
- Deity: Hanuman (Maruti)
- Language: Marathi
- Author: Samarth Ramdas (traditional attribution — the last stanza itself says "रामी रामदासाची"). PD (d. 1681).
- Size: refrain (ध्रु.) + 3 stanzas. A Bhupali is the morning wake-up song form (sung at dawn); this is the short Maruti bhupali, not the longer Kakad Aarti sets.
