# सत्राणे उड्डाणे — SOURCE.md

- **Title (Marathi):** सत्राणे उड्डाणे
- **Deity:** Hanuman / Maruti (श्री हनुमान)
- **Author:** Samarth Ramdas (1608–1681/82). Signature "रामी रामदासा शक्तीचा शोध" in the last stanza.
- **Language:** Marathi
- **Stanzas:** 2 numbered stanzas + 1 refrain (ध्रुवपद, "जय देव जय देव जय श्रीहनुमंता")

## Sources compared

1. Sant Sahitya — Hanuman Aarti (Maruti Aarti), attributed to Samarth Ramdas: https://www.santsahitya.in/arti/hanuman-aarti/ — this source itself notes a पाठभेद (variant reading) for "सुरवर, निशाचर".
2. Abhangvani — Hanumantachi Aarti: https://abhangvani.com/hanuman-arati (also checked against Milind S. Pandit's transliteration, https://www.milindspandit.org/mobile_aarati?transliteration=true, and Shubhdarshika, https://www.shubhdarshika.in/mr/info/hanuman-jayanti, which agree on the 2-stanza text)

## Variant readings found and decision

- A different Maruti aarti sharing only the first line circulates in some collections: its stanzas run "करि वज्रपुच्छ लंगूर परळी भजनी … / अंजनीसुता कपिकुळटिळका विशाळा … / रामदास विनवी जोडूनिया हात" with refrain "तुमचे चरणी ठेविले मस्तक अनंता". The 2-stanza Ramdas text in our file is attested by Sant Sahitya, Abhangvani, Milind Pandit, and Shubhdarshika; that version was NOT followed and is recorded here.
- Stanza 1, line 3: "कडाडिले ब्रह्मांड धाके त्रिभुवनी" (Sant Sahitya, Abhangvani) vs "गडबडिलें ब्रह्मांड धाके त्रिभुवनी" (Shubhdarshika) — kept "कडाडिले".
- Refrain, line 2: "तुमचेनि प्रतापे न भिये कृतांता" (Sant Sahitya, Milind Pandit) vs "तुमचेनी प्रसादें न भी कृतांता" (Abhangvani, Shubhdarshika) — kept "प्रतापे"; "प्रसादें" recorded as the variant.
- Stanza 2, line 1: "दुमदुमिले पाताळ उठला पडशब्द" (Sant Sahitya) vs "दुमदुमिली पाताळें उठिली प्रतिशब्द" (Shubhdarshika) — kept "पडशब्द".
- Stanza 2, line 2: "धगधगिला धरणीधर मानीला खेद" (Sant Sahitya) vs "थरथरला धरणीधर मानीला खेद" (Shubhdarshika) — kept "धगधगिला".
- Last line: "शक्तीचा शोध" (Sant Sahitya, Abhangvani) vs "शक्तीचा बोध" (Shubhdarshika) — kept "शोध".
- Stanza 1, line 4: "सुरवर नर निशाचर" — Sant Sahitya notes the variant reading "सुरवर, निशाचर" (without "नर"); kept "सुरवर नर निशाचर".
