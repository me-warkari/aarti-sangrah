# लवथवती विक्राळा — SOURCE.md

- **Title (Marathi):** लवथवती विक्राळा
- **Deity:** Shiva / Shankar (श्री शंकर)
- **Author:** Samarth Ramdas (1608–1681/82). Signature "रघुकुळटिळक रामदासा अंतरी" in the last stanza.
- **Language:** Marathi
- **Stanzas:** 4 numbered stanzas + 1 refrain (ध्रुवपद, "जय देव जय देव जय श्रीशंकरा")

## Sources compared

1. Maharashtraweb — Ganpati Aarti in Marathi, §3 (Lavthavti Vikrala): https://www.maharashtraweb.com/prayers/ganpati-aarti
2. Mantra Naad — Shankar Aarti: Lavathavati Vikrala: https://mantranaad.dnyanpower.com/shankar-aarti-lavathavti-vikrala/ (also checked against JaapDaily's Lavthavti Vikrala page, https://jaapdaily.com/learn/aarti/lavthavti-vikrala/, which agrees on the 4-stanza text)

## Variant readings found and decision

- First line: "ब्रह्मांडी माळा" (Maharashtraweb, Mantra Naad) vs "ब्रह्माण्डी माळा" (some lyric sites) — kept "ब्रह्मांडी माळा".
- Stanza 1, line 4: "तेथुनिया जळ निर्मळ वाहे झुळझुळा" (both compared sources). A divergent recension of this aarti circulates in some collections — its line 4 reads "तेथुनिया जळ मिळे निर्मळ वाळा", its stanza 2 is entirely different (मुंडमाळा / शेंदूर अंगी), and its stanza 3 substitutes "कैलासविहारी … मुक्तेश्वर चरणांबुजी" for the samudra-manthan stanza — so that recension was NOT followed; the 4-stanza text above is the one attested by Maharashtraweb, Mantra Naad, JaapDaily, and Brahmabhakti alike.
- Stanza 3: "देवी दैत्यी सागरमंथन पै केले" (Mantra Naad) vs "देवी दैत्य सागरमंथन" (Maharashtraweb) — kept "दैत्यी"; "हळाहळ" vs "हळहळ" — kept "हळाहळ".
- Refrain: "आरती ओवाळू तुज कर्पूरगौरा" (both compared sources). Some sources add "स्वामी शंकरा" / "भावर्थी ओवाळू" — refrain expansions, not included.
