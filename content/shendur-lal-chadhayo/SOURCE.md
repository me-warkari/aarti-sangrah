# SOURCE — शेंदुर लाल चढायो (Shendur Lal Chadhayo)

- Title: शेंदुर लाल चढायो अच्छा गजमुख को
- Deity: Ganesha
- Language: Hindi (not Marathi — labelled Hindi on the page; the wording mixes Hindi/Braj and Marathi forms, as sung in Maharashtra)
- Author: traditional / unattributed. The last verse contains the signature-like word “गोसावीनंदन”; no old manuscript or scholarly edition establishes Morya Gosavi as the author, so the Morya Gosavi attribution is NOT asserted. PD as a traditional text circulated for generations.
- Size: 3 stanzas + 1 refrain (the refrain, धृ, is repeated after each stanza when sung).

## Sources compared

1. JaapDaily, “Shendur Lal Chadhayo” — https://jaapdaily.com/learn/aarti/shendur-lal-chadhayo/ — full Devanagari text, 3 stanzas + refrain. Used as the base wording.
2. Saregama lyric page, “Shendur Lal Chadhayo Ganesh Aarti” — https://www.saregama.com/amp/song-lyrics/shendur-lal-chadhayo-ganesh-aarti_28403 — full Devanagari text, 3 stanzas + refrain. Agrees on structure and nearly all words; differs on the small spellings listed below. Cross-checked against BhaktiVerse (https://www.bhaktiverse.com/aarti/shendur-lal-chadhayo/) and Lifafa (https://www.lifafa.cc/blog/shendur-lal-chadhayo-aarti-lyrics-meaning) for the variant readings.

No text, meaning, transliteration, or presentation was copied from any lyric site; the text above was written from the compared wordings. The 1999 film arrangement (Vaastav) was NOT used as a source — its arrangement, performance, and film lyricist credit are separate copyrights.

## Variant readings found and decision taken

- “दोंदिल लाल” (JaapDaily, Saregama) vs “दोंदिलाल” in some copies: kept “दोंदिल लाल”.
- “सुत गौरिहर को” (JaapDaily, Saregama) vs “सुत गौरीहर को” (Lifafa, BhaktiVerse): kept “गौरिहर”.
- “सांई सुरवर को” (JaapDaily, Saregama) vs “साईं सुरवर को” (Lifafa): kept “सांई”.
- “संतत संपत सबही भरपूर पावे” (JaapDaily, Saregama) vs “संतति संपत्ति सभी भरपूर पावे” (Lifafa): kept “संतत संपत सबही”.
- “गुण गावे” (JaapDaily) vs “गुन गावे” (Saregama): kept “गुण गावे”.
- “कोटी सूरजप्रकाश” (JaapDaily) vs “कोटि सूरज प्रकाश” (Lifafa): kept JaapDaily's form.
- “शशिबिहारी” (JaapDaily) vs “शशिबिहारि” (Saregama): kept “शशिबिहारी”.
- Refrain: “जय जय श्री गणराज” (JaapDaily, BhaktiVerse) vs “जय जय जी गणराज” (Saregama, many recordings): kept “श्री गणराज”; the “जी” form is a sung variant. Some versions insert “जय देव जय देव” before the refrain; it is a sung interjection, not a verse, and is not included as text.
- One site (Hindukosh) gives a different second stanza (“अष्टौ सिद्धि नवनिधि दातार … पारवती नंदन शिवसुत त्राता”), which belongs to a different Ganesh aarti; it was excluded as a conflation, not a variant of this text.

## Disclaimer

This text is traditional and given as commonly sung. Its authorship is disputed/unestablished: the word “गोसावीनंदन” in the last verse looks like a poet's signature, but no source checked names an author on the strength of an old manuscript or scholarly edition, so no author is asserted here. The 1999 film version is a separate, copyrighted arrangement and is not the source of this text.
