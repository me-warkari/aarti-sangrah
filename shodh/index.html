शोध

आरती, देवता, संत किंवा मजकुरातील शब्द शोधा. शोध तुमच्या ब्राउझरमध्येच चालतो; काहीही सर्व्हरला पाठवले जात नाही. (शोधासाठी JavaScript लागते; ते बंद असेल तरी देवता व प्रसंग यांच्या जोडण्यांनी वाचता येते.)

शोध सुरू करण्यासाठी वर शब्द लिहा.

आरती संग्रह — मराठी व हिंदी आरत्या, मूळ मजकूर, मोफत. संकेतस्थळाचा कोड Apache 2.0; मजकुराचे परवाने प्रत्येक कृतीच्या स्रोत पानावर दिलेले आहेत.
